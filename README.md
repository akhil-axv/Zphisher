# Security Awareness Notes

This repository previously contained operational setup notes for a phishing toolkit. Those instructions have been removed.

## Purpose

Use this repository only for high-level security awareness documentation and defensive learning. Do not collect credentials, impersonate real services, or target people or systems without explicit authorization.

## Safer learning goals

- Learn how to recognize suspicious messages and look-alike websites.
- Understand why passwords and one-time codes must never be shared.
- Practice reporting suspicious activity through approved channels.
- Use organization-approved awareness materials and isolated training environments.

## Status

No phishing application, credential collection workflow, or launcher is provided here.
